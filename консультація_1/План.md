# RoamNest

## План на 10 тижнів

1. **1 тиждень** — підготовка, схема бази даних, API endpoints.
2. **2 тиждень** — створення mock-даних, старт розробки back-end-у.
3. **3 тиждень** — старт розробки React App.
4. **4 тиждень** — старт розробки UI.
5. ...

## Розподіл завдань

### Альона — back-end

Вимоги до back-end-у (Python, Django REST Framework):

- Схема бази даних:
  - які моделі (таблиці);
  - список API endpoints;
  - авторизація та перевірка доступу.

### Дмитро — front-end (React)

- Визначити, які дії повинні бути доступні ролі та як буде змінюватися UI.
- Запропонувати 1–2 варіанти компонента для календаря.
- Створити основу для React-застосунку, використовуючи Vite.
- Розглянути [Axios](https://axios.rest/) як бібліотеку для HTTP-запитів.
- Опціонально: Node.js — зручно для розробки.

### Поліна — UI (Tailwind CSS)

- Переглянути інформацію про Tailwind CSS.
- Визначити, які сторінки повинні бути.
- Визначити, які візуальні стани потрібні.
